# FlowFocus

Pomodoro timer, tasks, focus history, and a growing forest.

## Development

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Open http://localhost:3000. To verify a production build, run `pnpm build`.

## Deployment

This repository is connected to the existing Vercel project `v0-pomodoro-web-app`.
Push or merge changes into `main` to deploy to https://flowfocus.ivopfaffen.com.
Check the deployment status in Vercel after pushing.

Settings, tasks, and focus history are stored in the browser's local storage.
